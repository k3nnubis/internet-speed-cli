# Internet speed CLI

Консольный скрипт на Python, который скачивает файл по указанному HTTP(S)-адресу **10 раз последовательно**, каждый раз дожидаясь полного ответа. Печатает время и размер каждой загрузки, среднее время запроса, общий объём данных и скорость скачивания.

## Запуск

Нужен **Python 3.10+**. Сторонних зависимостей нет, устанавливать пакеты не нужно.

```sh
git clone https://github.com/k3nnubis/internet-speed-cli.git
cd internet-speed-cli
python speedtest.py "https://example.com/large-image.jpg"
```

Замените адрес на прямую ссылку на доступный файл. Кавычки важны для адресов с `&` и другими специальными символами. В Linux/macOS команда Python может называться `python3`, в Windows можно использовать `py`.

```sh
python speedtest.py "https://example.com/large-image.jpg" --timeout 60
python speedtest.py --help
```

`--timeout` задаёт таймаут отдельной блокирующей сетевой операции в секундах (по умолчанию 30). Это не ограничение длительности всей загрузки: пока сервер присылает данные, она может продолжаться дольше.

## Пример вывода

Условный пример для файла размером 1 MiB и десяти загрузок по 0,5 секунды:

```text
[1/10] 1048576 bytes in 0.500000 s
...
[10/10] 1048576 bytes in 0.500000 s

Average request time: 0.500000 s
Total downloaded: 10485760 bytes (10.000 MiB)
Download speed: 2.000 MiB/s (16.777 Mbit/s)
```

## Как считается результат

- Время каждого запроса измеряется через монотонный `time.perf_counter()` от начала подключения до полного чтения тела ответа. В него входят DNS, подключение, TLS для HTTPS, ожидание сервера и передача данных. Печать в консоль в замер не входит.
- Среднее время = сумма времени десяти запросов / 10.
- Общий объём = сумма фактически прочитанных байтов тела всех десяти ответов. HTTP-заголовки и накладные расходы протоколов не учитываются.
- Скорость = общий объём / сумма времени запросов. **MiB/s** — мебибайты в секунду (1 MiB = 1 048 576 байт); **Mbit/s** — мегабиты в секунду (1 Mbit = 1 000 000 бит, 8 бит = 1 байт).

Ответ читается блоками по 64 KiB и не сохраняется на диск или целиком в память. Скрипт запрашивает несжатое тело (`Accept-Encoding: identity`), сам его не распаковывает и передаёт `Cache-Control: no-cache`. HTTP-перенаправления обрабатывает стандартная библиотека; они могут добавлять сетевые запросы и входят во время загрузки.

При HTTP-ошибке, сетевой ошибке, таймауте или преждевременном обрыве ответа с объявленным размером скрипт останавливается с кодом **1**, показывает номер неудачного запроса в stderr и не выводит итог по неполной серии. Ошибка аргументов — код **2**, Ctrl+C — **130**, успешное выполнение — **0**. Повторных попыток нет.

Это скорость загрузки **с выбранного сервера**, а не гарантированная пропускная способность интернет-канала. На результат влияют размер файла, задержка, сервер, кэширование и текущая загрузка сети. Выбирайте достаточно большой файл и учитывайте трафик: он будет скачан десять раз.

## Проверка

```sh
python -m unittest -v test_speedtest.py
```

Тесты запускают локальный HTTP-сервер и не обращаются в интернет. Проверяют десять последовательных запросов, полное чтение отложенного тела, подсчёт объёма и скорости, HTTP-ошибки, обрыв ответа, таймаут, перенаправления и проверку аргументов.
